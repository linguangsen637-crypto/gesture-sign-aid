# 美国手语支持范围

项目采用 WLASL 的 American Sign Language（ASL）词汇。第一版使用 `cup`，在取物场景中映射为自动取杯请求；现有 `water`、`tissue` 映射供后续扩展。

`configs/sign_lexicon.json` 记录上游来源、固定提交、标签和意图。`cup`、`water`、`tissue` 分别有 13、18、8 条标注记录，实际视频可用性和识别性能待验证。

## 验证流程

1. 获取固定版本子模块，查询所选词汇。
2. 准备视频子集，保留上游训练、验证和测试划分。
3. 检查视频中的完整动作及相关身体部位。
4. 请熟悉 ASL 的人员复核标签与演示动作，记录复核信息。
5. 使用独立测试片段和现场输入评估，加入未知词及不完整动作。

参考示范、训练样本和评估样本分别记录。自采片段保留参与者授权。上游数据使用遵循其 README 与协议，详见 [WLASL 指南](wlasl.md) 和 [来源说明](../THIRD_PARTY_NOTICES.md)。

## 识别接口

识别模型观察动作片段并输出词汇标签，`request_from_gloss` 将支持的标签映射为 `RetrievalRequest`。其他词汇输出为 `unclear`。单词到物品请求的映射是项目定义的交互规则。
