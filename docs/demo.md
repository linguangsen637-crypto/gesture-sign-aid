# Demo 计划

## 五分钟展示

1. 用 30 秒介绍目标用户与取物场景。
2. 用 30 秒说明WLASL 支持的 ASL 词汇和确认方式。
3. 用约两分钟展示需求识别、确认、机械臂执行和结果验收。
4. 用一分钟说明示教数据、训练和实际测试结果。
5. 用一分钟介绍当前支持范围、团队分工及后续改进。

预留问答时间，展示前按现场要求完成安全检查。

## 展示资料

- 手语资料来源与核验记录。
- 机器人示教和训练记录。
- 现场连续执行视频及备份视频链接。
- 实际测试数量、成功率与耗时。
- 按活动要求保留 Grok Bot、Cursor 的实际参与记录和开源来源。

## 运行安排

用户在工作范围外表达需求，机械臂放置物品并退回后取物。设备负责人确认速度、力度和停止机制，每次运行安排急停负责人。演示使用获得授权的素材。
