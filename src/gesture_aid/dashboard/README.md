# 操作界面接入

界面负责人通过 `RetrievalWorkflow` 接入共享流程。

- 显示手语识别结果、请求物品和当前状态。
- 识别器对有效动作生成稳定 `request_id`，调用 `submit` 自动执行。忙碌期间暂停接收新动作，同一动作片段的重试沿用原 ID。
- 执行结束进入 `waiting_result`，由独立结果检测调用 `record_result`，该检测模块待接入。
- 完成后调用 `reset`，再接受下一次请求。

当前执行接口为同步调用。真实设备接入时，由后端工作线程或任务队列管理执行，并为停止、超时和故障建立独立的控制路径。界面停止按钮必须连接真实执行器的停止机制。
